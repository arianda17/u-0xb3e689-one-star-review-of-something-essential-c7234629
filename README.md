# One-Star Review of Something Essential

`I gave sleep eight hours and woke up tired, which is the worst return policy I have ever used.`

## Run

```
python3 main.py
```

The program defines the review line as a constant, asserts it is a single UTF-8 line of 1–160 characters that is not only whitespace, writes it to `/output/entry.txt` (creating the directory if needed), and prints it.
